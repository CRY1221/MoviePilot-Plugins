## 解释及边界

计算缓存没有删除输入候选，MP 原生规则、匹配及最终去重仍执行。过滤规则内部也可能解析，同名消歧缓存不会自动加速整个匹配环节。

上述阶段值是各工作线程的累计墙钟耗时，存在并行重叠；不能相加作总耗时，也不是纯 CPU 时间。命中次数不能直接乘平均未命中时间作为已节省秒数，因为并发等待、不同输入复杂度和其他任务争用未被控制。

本次交付完成了安全计算复用和性能观测。尚未解决规则过滤重复工作、分页后的批次交付时机及线程数选择；没有实测 TG 消息收发或真实新订阅下载。智能助手工具调用成功也不等于完整 TG / 订阅业务验收。
