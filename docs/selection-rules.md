# 选种规则

## 排序

从高到低：

1. 分辨率：4K（`4K` / `UHD` / `2160P` / `2160I`）> 2K（`2K` / `QHD` / `1440P` / `1440I`）
   > 1080P（`1080P` / `1080I` / `FHD`）> 720P（`720P` / `720I`）
2. 同一分辨率档内，中文字幕优先：`-C` / `_CH` / `CHS` / `CHT` / `中字` / `字幕`
3. 同一档、同一字幕条件下，按体积从大到小

名称里看不出分辨率的候选与 1080P 同档，按体积参与比较。

## 硬性排除

- 无码破解：`-U` / `-UC` / `uncensored` / `uncen` / `leaked` / `leak` / `無碼` / `无码` /
  `無修正` / `无修正` / `破解` / `无码流出` / `無碼流出` / `モザイク破壊` / `リーク`
- AI 拉伸或修复：独立的 `AI` 标记（`.AI.` / `[AI]` / `-AI`）/
  `AI高画質リマスター` / `4Kリマスター版` / `リマスター` / `Remaster` / `Upscale` /
  `修复版` / `高清修复` / `4K修复` / `超分` / `补帧` / `插帧`

以上关键词按 2026-10-20 实际抓取的 514 条磁力名称核对过：无码类命中 13 条，
AI 类在 JavBus / JavRanking 的磁力名称里没有出现（AI 版主要在中文站，命名见
`AI高画質リマスター`、`.AI.`）。
- 假 4K：标了 `4K` / `UHD` / `2160P` / `2160I`，但体积 **< 5GB**
- 480P / 480I / 360P / 360I / 240P / 240I
- 小于 2GB（2048MB）的候选（默认值，可在设置里改）
- 广告或非视频：推广域名、`zip/rar/7z` 压缩包、游戏大全、推广、广告

720P 不再直接排除，只排在 1080P 之后。

## 分辨率标签怎么认

没有哪个片子会在名称里标码率，所以只按名称里显式的分辨率标签排序。

- `4K` / `UHD` / `2160P` / `2160I` → 4K
- `2K` / `QHD` / `1440P` / `1440I` → 2K
- `1080P` / `1080I` / `FHD` → 1080P
- `720P` / `720I` → 720P
- 名称里没有分辨率 → 按 1080P 档，比体积
- `6K` / `8K` 不当作分辨率，也不换算成码率；`HD` 不单独加分

洗版时真实质量最终由下载后的 ffprobe 复核，码率参与是否替换的判断；普通下载不探测。

## 识别筛选规则开关

设置页有「启用识别筛选规则」开关，默认开启。关闭后：

- 不排除无码、AI 拉伸、假 4K、480P、小视频和广告
- 直接按体积选最大的一条

「候选最小体积（MB）」默认 2048（2GB），只在这个开关开启时生效，只管选种。
整理落盘目录时仍按 300MB 的小视频阈值清理垃圾文件，两者互不影响。

目录里没有可用视频时（所有视频都小于阈值，或根本没有视频文件，比如只有 `.iso` 镜像和广告），
插件不会重试同一个种子：删除该候选已下载的目录、移除 115 离线记录，直接换下一条候选。
所有候选都没有可用视频时任务才失败，提示“所有候选都没有可用视频”。

## 洗版比较

开启洗版后，候选先按估算质量排序，取前 20 条，再截断到 `max_candidates`。
下载前粗判、下载后复核：

- 候选高度高于库内 → 可洗
- 高度相同，候选码率达到库内 **1.15 倍** → 可洗
- 候选体积达到库内 **1.5 倍** → 可洗
- 候选带中文字幕、库内没有，且高度不低于库内 → 可洗
- 下载后 ffprobe 复核不满足上述条件 → 删除文件，标记跳过

`force=true` 绕过下载前粗判，但仍要走下载后的 ffprobe 复核。

## 洗版时的低清处理

只有洗版才会在下载后探测真实分辨率；普通下载不跑 ffprobe。

- 洗版探测高度 `< 720`：删除已下载文件，换下一条候选；
- 所有候选都 `< 720`：任务失败，提示“所有候选下载后都低于 720P”，不入库；
- ffprobe 失败、高度未知：不按低清处理，保留文件。

## 文件命名

- 单文件：`<番号>.ext`；中文字幕 `<番号>-C.ext`
- 多段：`<番号> - part1.ext`、`<番号> - part2.ext`；中文字幕 `<番号>-C - part1.ext`
- 目录：`<番号>/`
- 文件名不再带分辨率；分辨率只用于洗版比较和低清判断。

## 多段资源

识别 `CD1/CD2`、`part1/part2`、`pt`、`disc/disk`、结尾 `-1/-2` 等分段。

整理时：

- 默认只保留主视频，但同一部影片的多个分段**全部保留**
- 小于 50MB 的伪分段不参与识别
- 已有完整成片时，不让同名分段覆盖成片
- 文件按 Emby 多段命名改成 `<名称> - part1.ext`、`<名称> - part2.ext`
- 字幕跟随对应分段改名，例如 `<名称> - part1.chs.srt`

## 已知边界

- 多段识别依赖文件名；`A/B`、`上/下`、`前篇/后篇` 等命名暂未覆盖
- 磁力名称不提供做种数、码率或真实分辨率，体积仍是主要兜底信号
