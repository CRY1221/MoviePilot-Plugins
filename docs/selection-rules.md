# 选种规则

## 排序

从高到低：

1. `第一会所新片` / `SIS001`
2. 中文字幕：`-C` / `_CH` / `CHS` / `CHT` / `中字` / `字幕`
3. 4K / UHD / 2160P / 2160I，且体积 **≥ 5GB**
4. 其余，按体积从大到小

同一档内按体积从大到小取。

## 硬性排除

- 无码破解：`-U` / `-UC` / `uncensored` / `無碼` / `无码` / `破解`
- 假 4K：标了 4K/UHD/2160P，但体积 **< 5GB**
- 720P / 720I
- 广告或非视频：推广域名、`zip/rar/7z` 压缩包、游戏大全、推广、广告

## 为什么不把分辨率当主要依据

磁力名称里的 `HD` / `FHD` 经常和实际分辨率不一致，`HD` 可能只是 720P，`FHD` 也可能只是 1080P。
所以：

- 只把明确的 `720P` 当作排除条件
- 不按 `HD` / `FHD` 给候选加分
- 主要依据是：中文字幕、可信 4K（≥5GB）、体积

## 多段资源

识别 `CD1/CD2`、`part1/part2`、`pt`、`disc/disk`、结尾 `-1/-2` 等分段。

整理时：

- 默认只保留主视频，但同一部影片的多个分段**全部保留**
- 小于 50MB 的伪分段不参与识别
- 已有完整成片时，不让同名分段覆盖成片
- 文件按 Emby 多段命名改成 `<名称> - cd1.ext`、`<名称> - cd2.ext`
- 字幕跟随对应分段改名，例如 `<名称> - cd1.chs.srt`

## 已知边界

- `第一会所新片` 只出现在 JavBus 磁力名称里；JavRanking 缓存通常没有这个标志
- 多段识别依赖文件名；`A/B`、`上/下`、`前篇/后篇` 等命名暂未覆盖
- 磁力名称不提供做种数、码率或真实分辨率，体积仍是主要兜底信号
