# 选种规则

## 排序

从高到低：

1. 中文字幕：`-C` / `_CH` / `CHS` / `CHT` / `中字` / `字幕`，且体积不低于最大候选的 **50%**
2. 可信 4K：明确标 `4K` / `UHD` / `2160P` / `2160I`，且体积 **≥ 5GB**
3. 其余，按体积从大到小

同一档内按体积从大到小。中文字幕候选不到最大候选一半时，不再享受第一档，按体积正常竞争。

## 硬性排除

- 无码破解：`-U` / `-UC` / `uncensored` / `無碼` / `无码` / `破解`
- 假 4K：标了 `4K` / `UHD` / `2160P` / `2160I`，但体积 **< 5GB**
- 720P / 720I
- 480P / 480I / 360P / 360I
- 小于 300MB 的视频（默认值，可在设置里改）
- 广告或非视频：推广域名、`zip/rar/7z` 压缩包、游戏大全、推广、广告

## 分辨率标签怎么认

`4K` 和 `2160P` 都是 4K，没有哪个片子会在名称里标码率。

- `4K` / `UHD` / `2160P` / `2160I` 都算 4K
- `1440P` / `1440I` 才算 1440；裸 `2K` 含义不固定，不猜
- `1080P` / `1080I` / `FHD` 算 1080；`HD` 不参与判断
- `6K` / `8K` 不当作分辨率，也不换算成码率

`HD` / `FHD` 经常和真实分辨率不一致，所以选种不靠它们加分。洗版时真实质量最终由下载后的
ffprobe 复核；普通下载不探测。

## 识别筛选规则开关

设置页有「启用识别筛选规则」开关，默认开启。关闭后：

- 不排除无码、假 4K、720P/480P、小视频和广告
- 直接按体积选最大的一条

「小视频阈值（MB）」默认 300，只在这个开关开启时生效。整理落盘目录时，
小于阈值的视频文件也会被当作垃圾删除；如果目录里所有视频都小于阈值，插件会
报错停止，不会把目录清空。

## 洗版比较

开启洗版后，候选先按估算质量排序，取前 20 条，再截断到 `max_candidates`。
下载前粗判、下载后复核：

- 候选高度高于库内 → 可洗
- 高度相同，候选码率达到库内 **1.15 倍** → 可洗
- 候选体积达到库内 **1.5 倍** → 可洗
- 候选带中文字幕、库内没有，且高度不低于库内 → 可洗
- 下载后 ffprobe 复核不满足上述条件 → 删除文件，标记跳过

`force=true` 绕过下载前粗判，但仍要走下载后的 ffprobe 复核。

## 洗版时的低清处理

只有洗版才会在下载后探测真实分辨率；普通下载不跑 ffprobe。

- 洗版探测高度 `< 720`：删除已下载文件，换下一条候选；
- 所有候选都 `< 720`：任务失败，提示“所有候选下载后都低于 720P”，不入库；
- ffprobe 失败、高度未知：不按低清处理，保留文件。

## 文件命名

- 单文件：`<番号>.ext`；中文字幕 `<番号>-C.ext`
- 多段：`<番号> - part1.ext`、`<番号> - part2.ext`；中文字幕 `<番号>-C - part1.ext`
- 目录：`<番号>/`
- 文件名不再带分辨率；分辨率只用于洗版比较和低清判断。

## 多段资源

识别 `CD1/CD2`、`part1/part2`、`pt`、`disc/disk`、结尾 `-1/-2` 等分段。

整理时：

- 默认只保留主视频，但同一部影片的多个分段**全部保留**
- 小于 50MB 的伪分段不参与识别
- 已有完整成片时，不让同名分段覆盖成片
- 文件按 Emby 多段命名改成 `<名称> - part1.ext`、`<名称> - part2.ext`
- 字幕跟随对应分段改名，例如 `<名称> - part1.chs.srt`

## 已知边界

- 多段识别依赖文件名；`A/B`、`上/下`、`前篇/后篇` 等命名暂未覆盖
- 磁力名称不提供做种数、码率或真实分辨率，体积仍是主要兜底信号
