# 实际 Rust 路径与速度异常核查

2026-10-13，MoviePilot v3.1.4 当前容器。已部署诊断版本 3.6.2；89 项离线测试通过。诊断包装器只记录原生调用，不改变返回值、异常或规则。

## 已确认的实现偏差

- 先前只分析过滤/匹配整段日志，没有细分实际内核执行路径，不能据此判断 Rust 本体耗时。
- 当前 make_read_pages 在一个站点/关键词的分页循环结束后才 return 合并资源；不是既定的逐页处理。
- 相同资源可被不同中英关键词查询返回；没有证据证明插件正常调度会重复发送完全相同的请求。原生 manual.read 另有上一页摘要缺失时补取上一页的恢复路径，不能混同为正常调度重复请求。

## 当前运行状态

系统 env 返回 RUST_ACCEL / RUST_ACCEL_AVAILABLE / RUST_ACCEL_ENABLED 均 true；RUST_ACCEL_REQUIRED=false。普通 Python，PYTHON_FREE_THREADED=false、PYTHON_GIL_ENABLED=true。这些开关本身不证明每次过滤走 Rust。

## 兰香如故全站实测（3.6.1）

完整耗时 120.33 秒，首批 13.38 秒，1897 个候选、779 个结果。

| 观测点 | 次数 | 累计墙钟秒 | 当前线程累计 CPU 秒 | 返回 None |
|---|---:|---:|---:|---:|
| Rust 过滤入口 | 10 | 0.2153 | 0.0721 | 10 |
| Rust 资源解析入口 | 2160 | 307.4939 | 98.8264 | 0 |
| Rust 结果转 Meta 对象 | 2160 | 0.2302 | 0.2002 | 0 |
| 规则组读取 | 10 | 0.0037 | 0.0036 | 0 |
| 进度更新 | 1524 | 7.7671 | 1.8321 | 正常无返回值 |
| 缓存键解析配置读取 | 1454 | 0.0292 | 0.0222 | 不适用 |

没有观察到 _build_python_meta_info 调用，即资源解析走 Rust；过滤入口每次都返回 None，按 FilterModule.filter_torrents 的原生逻辑进入 Python 过滤兜底。

解析缓存命中 748，实际计算 706；原生解析计算累计 97.6482 秒，复制累计 0.1932 秒，命中等待累计 16.0296 秒。复制与规则组读取不是主要耗时。Rust 解析调用数 2160 超过匹配阶段实际计算 706，额外解析与 Python 过滤大小规则的 MetaInfo 调用路径相符；不能把全部次数直接等同于唯一资源数。

多线程墙钟时间重叠，且当前线程 CPU 时间不涵盖可能的 Rust 内部额外线程，所以不能将各项相加或将墙钟减 CPU 全部解释为 GIL。98.8264 / 2160 约为 45.8 毫秒当前线程 CPU / 调用，不能等同于 V2 同输入性能对比。

## 单站复测与具体回退原因（3.6.2）

兰香如故、天空站、同一原生网页搜索路径：46.37 秒，4 个候选、3 个结果。一次 Rust 过滤返回 None，原生捕获的异常为：

```
ValueError: Parsing error at position 237: Invalid character class
```

Rust 解析调用 6 次，累计墙钟 0.4833 秒、当前线程 CPU 0.4831 秒；没有 Python 解析回退。匹配实际解析 3 次，另外的解析由过滤链产生。缓存复制 0.0003 秒。

因此可以确认：本实例搜索的规则筛选未实际完成 Rust 快路径，主要原因是规则相关解析错误；资源元数据解析则确实走 Rust。不能以“调用 MP 原生模块”替代这个事实。

## 规则只读快照

读取了原生 /rule/custom、/rule/groups、/rule/builtin。前置过滤被全局搜索使用，引用 WhiteList 等规则。WhiteList 长正则存在 `[-@&\\[(_.]` 一类字符组，Python re 能编译它；这是排查 Rust 字符组不兼容的候选，尚未用 Rust 单规则隔离验证，不能宣称已锁定唯一责任规则。没有修改用户规则。

V2 2.6.0 自己固定选择“前置过滤”及媒体类别规则；V3 使用 MP 原生搜索选择的规则。两者共用原生过滤模块，但规则集合、去重位置、抓取页数和资源数量未受控。现有数据不足以量化 V2 到 V3 的纯引擎性能变化。

## 修复次序

先单规则隔离确认不兼容表达式，验证 Python/Rust 等价写法或宿主兼容修正；不能为了使用 Rust 跳过规则或改变过滤结果。随后补齐逐页交付，并检查过滤阶段重复解析是否可在原生接口边界复用。以同一候选数据集验证最终资源和优先级一致性。
