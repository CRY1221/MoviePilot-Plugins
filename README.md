# MoviePilot 插件 - 极速搜索 (FastSearch)

MoviePilot 极速搜索增强插件，专注提升多站点搜索效率与选种质量。

## 核心特性

1. **跨站点并发检索**：对已配置启用的站点并发发起搜索请求，消除串行网络等待瓶颈。
2. **同站点 3 秒安全频控**：同站点内的多轮搜索或翻页请求强制排队并等待 3 秒，防止触发 PT 站点 Flood 防刷风控与封禁机制。
3. **内存级识别防抓错**：抓取后直接在内存中调用系统的 `TorrentHelper.match_torrent` 完成媒体识别消歧，剔除不同作品同名噪点。
4. **原生 Rust 规则链秒级评级**：内存直接调用系统规则链，交由底层 Rust 引擎（`filter_torrents`）毫秒级完成优先级过滤与打分。
5. **完结全集包强力提权**：自动识别影视完结状态（Ended / Released），对整季全集包施加高权重优先置顶。
