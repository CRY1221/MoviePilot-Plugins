# 极速搜索 · FastIntersectSearch

MoviePilot V3 搜索调度插件。加速网页、TG 等通知渠道、智能助手和新订阅首次搜索；媒体识别、规则过滤、优先级排序、下载选择及订阅结算交给 MP。

## V3 实现

- 网页：各站点独立推进关键词；保留原生流式事件、来源标识及翻页事实。
- TG / 智能助手：复用原生搜索链、跨站并发与分页。确认没有额外插件搜索源时，移除关键词之间的整轮随机等待。
- 同站保护：同步与异步搜索共用进程内队列，同站只允许一个真实在途请求；默认 **3 秒**，从**上一次请求结束**的时刻开始计算（与旧版一致），站点自身的间隔与自动订阅更严的限制继续生效。
- 首订：仅匹配 `source=new` 且执行身份一致的任务，并发预取每站当前一页；原生 `step → ready → choose` 消费结果。后续页继续由原生扫描驱动，不固定为第一页。
- 排序：精准搜索保留原生结果处理；标题搜索的最终展示也调用 MP 的 `TorrentHelper.sort_torrents`。不会给全集自定义加分或保留已被规则拒绝的资源。
- 音乐：纯音乐透传；被识别为电影或电视剧的演唱会、歌舞剧视频按影视处理。
- 工具：保留 `fast_intersect_search`，提供显式参数结构。标题和媒体 ID 两种模式；只搜索，不主动提交下载。

代码位于 `plugins.v3/fastintersectsearch/`，清单为 `package.v3.json`。原 `plugins.v2/` 与 `package.v2.json` 冻结保留。

## 配置与迁移

设置页只保留需要用户决策的控件：`enabled`、两个数值参数，以及两个可选功能开关。

| 配置 | 是否出现在设置页 | V3 行为 |
| --- | --- | --- |
| `enabled` | ✅ | 默认关闭；启用前核验宿主接口，失败则不安装调度适配 |
| `site_sleep_seconds` | ✅ | 默认 3 秒，从上次请求**结束**时刻起算；不改动 MP 的站点配置 |
| `max_pages_per_site` | ✅ | 每站每关键词最多翻页数，默认 1（1-20）；空页或出错自动停止 |
| `accelerate_new_subscribe` | ✅ | 默认开启：接管订阅搜索，并发预取各站待请求页 |
| `single_group_download` | ✅ | 默认开启：订阅按集下载时把候选收敛到同一制作组；认不出组的资源放行 |
| `streaming_pipeline` | — | 默认行为，不给开关：过滤/匹配与抓取重叠执行 |
| `bilingual_names` | — | 默认行为，不给开关：只用原名、中文名、英文名（最多 3 个）替代 MP 的全别名展开；显式关键词与音乐搜索不受影响 |

后两项仍从配置读取、缺省为开：老配置里显式关掉过的仍然算数，只是界面上不再显示。
| `bilingual_search` | 不再单独控制；关键词与别名遵循 MP 系统配置 |
| `search_timeout` | 不再独立截断；请求超时由 MP 管理，取消时等待真实请求收尾 |
| `default_top_k` | 不再全局裁剪；工具参数 `top_k` 仅裁剪最终展示，0 表示全部 |
| 旧 `en_title` / `require_complete=true` | 工具明确拒绝，避免承诺没有实现的关键词或完整包过滤 |
| 历史耗时数据 | 不迁移为当前数据；新大盘统计当前进程最近 72 小时、最多 5000 次请求样本 |

分页范围遵循 MP：普通搜索页数、网页按需续页、订阅 `smart/full/single_page` 各自保持原生语义。“支持抓取后页”不意味着覆盖用户设置强制扫描全部页面。完整包保护依赖原生收集屏障与下载链；smart 部分缺集搜索仍可能原生早停。

## 验证与当前边界

开发基线：MoviePilot `v3.1.4`，提交 `09f62ff87e196df9e39a6422f23c23860610d96a`。使用私有内核接口，未来相同签名但不同语义的版本仍需重新验证。

离线测试使用固定内核中的原始函数定义和纯领域模块，对外部网络、数据库、识别服务及下载提交使用替身。未完整启动 MP 容器，不能把离线通过称为线上联调或性能验收。详情见 [验证记录](docs/refactor-validation.md) 和 [设计说明](docs/refactor-design.md)。

测试环境：Python 3.14、pytest、Pydantic 2。将固定内核 checkout 放在仓库同级 `kernel-reference/`，或通过环境变量 `MP_KERNEL_REFERENCE` 指定路径，再运行 `python -m pytest tests -q`。

首次从 2.6.0 切换时应安排正常重启：旧版已经安装的猴子补丁不能靠猜测原方法安全解开。检测到未知包装器时 V3 保持关闭。当前代码只在本地实现，尚未推送或部署到 MP。

工具返回 `results`、`empty`、`failed` 或 `incomplete`；原生接口不提供完整的逐站成功报告，因此另标记 `site_completeness=unknown`，不将空结果解释成所有站点都成功。网络异常交由 MP 工具框架报告，取消不会伪装成正常完成。

限制：站点锁只覆盖本进程经 SearchChain 的影视资源请求，不是跨容器或全系统站点限流器。额外插件搜索源保留原生等待。首订预取可能产生少量最终未消费的请求，但不会替它们推进游标、写检查点或提交下载。
